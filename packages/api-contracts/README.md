# @pillar/api-contracts

Public API contract package for Pillar v1.

## Scripts

- `pnpm --filter @pillar/api-contracts typecheck`
- `pnpm --filter @pillar/api-contracts build`
- `pnpm --filter @pillar/api-contracts validate:openapi`
- `pnpm --filter @pillar/api-contracts test`
- `pnpm --filter @pillar/api-contracts test:golden`
- `pnpm --filter @pillar/api-contracts lint:public-contract`
- `pnpm --filter @pillar/api-contracts codegen`
